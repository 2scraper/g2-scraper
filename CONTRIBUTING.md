# Contributing

1. Fork, branch, make your change.
2. `pip install -r requirements-playwright.txt` (or `-selenium` / `-puppeteer`) and run `python3 smoke_test.py` — it must pass with **no** engine installed at all, so if you're only testing one engine, that's still a meaningful run. If you touched an engine script's control flow (not just `g2_parser.py`), also run `python3 local_e2e_test.py --engines <whatever you installed>` — it drives a real browser through the real pipeline against a local stand-in for g2.com, no live-site access or 2Captcha key needed, and it's what caught the pagination and user-agent bugs in CHANGELOG.md's 2026-09-22 entry that neither the offline suite nor a code review had.
3. **If you touched `g2_parser.py`: read its module docstring first.** It is the only file in this repo carrying any g2.com knowledge (CLAUDE.md §5/§7), and it separates CONFIRMED facts (taken from a real live capture on 2026-09-22 — the category card's `data-event-options` JSON, the product page's `SoftwareApplication` JSON-LD, the pagination markup, DataDome, the AI-crawler robots.txt group) from BEST-EFFORT guesses (the pricing-page text parser, which has no JSON behind it at all). If you have a real, scrubbed `--dump-html` capture that confirms or corrects any of it, save it under `tests/fixtures/`, update `g2_parser.py` to match, and remove the relevant note. Don't remove one without a capture backing it up. Two specific gaps are waiting for exactly this: `GENERAL_DISALLOWED_PATTERNS` (the `User-agent: *` group of `https://www.g2.com/robots.txt`, deliberately left empty rather than guessed) and a parser for `https://www.g2.com/categories/{slug}/grids.json`, whose field names were never captured.
4. **Never merge the two rating scales.** g2.com publishes a 0-5 star rating on category cards and a 0-10 composite score on product pages, and an individual embedded review is 0-5 again. `output_writer.Product` keeps them as `rating_5` and `rating_10`, and nothing in this repo averages or converts between them. A PR that introduces a single `rating` column will be rejected on sight, however tidy it looks.
5. **Captcha auto-solve is armed on every page path, and every `count_product_links` matches its own call site.** Both of these are real bugs this family has already shipped and fixed once (shein-scraper, 2026-09-22 — `g2_parser.py`'s module docstring has the full write-up). If you add a new page shape, it gets auto-solve arming and its own counter, and `smoke_test.py` gets a structural (AST-level) check for both.
6. Keep the three engines behaving identically: same exit codes, same `Product` schema, same CLI flags, same routing between a category URL, a product `/reviews` URL and a `/pricing` URL. If one needs to diverge (see `selenium_scraper.py`'s CDP-credential limitation for an example), say why in a comment.
7. Open a PR. CI runs the offline suite on two Python versions plus one `engine-smoke` job per engine, each in its own virtualenv, plus a daily `canary` job that runs a real, multi-page category run against the live site once `G2_PROXY` (and, for the managed-browser leg, `G2_CDP_ENDPOINT`) is configured as a repo secret — it skips cleanly, not red, until then (see `TESTING.md`).

Bug reports and feature requests: open an issue. Please include the exact command you ran and the `.meta.json` sidecar from the run (or note that none was written — that's itself informative, see `output_writer.finish_run`'s docstring), not just a description. If you're reporting that zero products came back, attaching a `--dump-html` capture is the single most useful thing you can add. If you hit a DataDome wall, note whether `--proxy`/`--proxy-file` was set (DataDomeSliderTask has no proxyless path — see README) and whether it recurred on a retry with a different proxy/fingerprint — what helps most is knowing both what does and doesn't get challenged in the first place, and whether the challenge iframe this repo detects (`geo.captcha-delivery.com/captcha/?...` OR `.../interstitial/?...` — both recognized as of 2026-09-22, see `tests/fixtures/g2_datadome_interstitial.html` for the real captured shape) actually matched what g2.com presented on YOUR run; if it's a third shape neither pattern catches, that's exactly the kind of real capture worth attaching.
